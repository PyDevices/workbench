# Open Workbench

There's nothing to install. Open <https://pydevices.github.io/workbench/> in a browser and the editor, file manager, terminal and simulator are all there.

## Install it as an app

Workbench is a progressive web app, so a browser can install it and open it in its own window. In Chrome or Edge, use the install icon at the right of the address bar. On Android, use "Add to Home screen" or "Install app". On iOS, use "Add to Home Screen" from the Share menu in Safari.

![Workbench installed as an app on a desktop](../images/screenshot-desktop-pwa.png)

## Which browser

The simulator runs in any modern browser. Connecting a real board over USB or Bluetooth needs Chrome, Edge, Opera or Brave. See [Browser and platform support](../reference/browser-support.md).
