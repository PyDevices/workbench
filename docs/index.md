# Workbench

Workbench is a MicroPython IDE for the browser, with a built-in device simulator. Live at <https://pydevices.github.io/workbench/>.

## Get started

- [Open Workbench](get-started/install.md): in a browser, or installed as an app.
- [Run your first program](get-started/first-program.md): in the simulator, no board needed.
