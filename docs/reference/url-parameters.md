# URL parameters

Workbench reads these from the address it's opened with.

| Parameter | Does | Guide |
|---|---|---|
| `vm=1` | starts the simulator on open | [Open a gallery example](../guides/open-a-gallery-example.md) |
| `example=<name>` | opens one gallery card: writes its files to the connected device and opens its entry file | [Open a gallery example](../guides/open-a-gallery-example.md) |
| `install=<link>` | installs a package on the board once one is connected | [Share a package](../guides/share-a-package-with-an-install-link.md) |
| `wss=<id>` | connects to a board through the secure WebSocket relay | [Connect over the internet](../guides/connect-over-the-internet.md) |
| `rtc=<id>` | connects over a peer-to-peer WebRTC link, set up by the [bridge page](https://pydevices.github.io/workbench/bridge.html) | |
