# Changelog

Each Workbench release is a plain `vX.Y.Z` tag with notes and the built site attached: <https://github.com/PyDevices/workbench/releases>.

The MCP tool in `mcp/` is released separately, with `mcp-v*` tags. Tags `v0.5.x` and `v0.6.x` are [ViperIDE's](how-it-works/viperide-fork.md), from before the fork.
